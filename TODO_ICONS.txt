     │ icon-512-maskable.png   │ 512×512   │ 10% (#0e0d0b)     │
     │ apple-touch-icon.png    │ 180×180   │ Aucun             │
     └─────────────────────────────────────────────────────────┘
  
  4. REMPLACER les 4 fichiers dans le dossier: public/
  
  5. COMMIT et PUSH:
     cd "C:\Users\MAGMA BETON\Downloads\taqendurt-projet (1)"
     git add public/*.png
     git commit -m "feat(pwa): regenerate icons from current logo"
     git push origin main
  
  6. APRÈS DÉPLOIEMENT, sur ton téléphone:
     - Désinstaller l'ancienne PWA "Taqendurt" ou "Borboleta"
     - Vider le cache du navigateur
     - Fermer tous les onglets
     - Rouvrir: https://myrobe.giize.com
